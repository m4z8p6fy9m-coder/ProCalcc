# ProCalc

Ein moderner, responsiver und wissenschaftlicher Taschenrechner als installierbare Web-App.

## Funktionen

- Grundrechenarten, Klammern, Potenzen und Prozentrechnung
- `sin`, `cos`, `tan`, `ln`, `log`, Quadratwurzel, π und e
- Grad- und Bogenmaß (DEG/RAD)
- Speicherfunktionen MC, MR, M+ und M−
- Lokaler Rechenverlauf
- Dunkler und heller Modus
- Tastaturbedienung, responsive Darstellung und Offline-Unterstützung
- Eigener sicherer Ausdrucksparser ohne `eval`

## Lokal starten

```bash
npm start
```

## Tests

```bash
npm test
```

## GitHub Pages

Unter **Settings → Pages** als Quelle **Deploy from a branch**, Branch **main** und Ordner **/(root)** wählen.
